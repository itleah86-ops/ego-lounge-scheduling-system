# The EGO Lounge Scheduling System

## Overview
This is a Python-based salon scheduling application for booking and viewing client appointments.

## Features
- Book appointments
- View schedule
- Update appointments
- Cancel appointments
- Prevent double-booking
- Save appointments in a JSON file

## Folder Structure
- `src/` = Python code
- `data/` = appointment data
- `tests/` = test notes
- `docs/` = project documentation

## System Requirements
- Python 3.11 or later

## How to Run
1. Open a terminal or command prompt
2. Navigate to the project folder
3. Run:

```bash
python src/main.py
