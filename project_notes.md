# Project Notes

## Project Title
The EGO Lounge Scheduling System

## Purpose
This software helps manage salon appointments by allowing the user to:
- book appointments
- view the schedule
- prevent double-booking

## Current Features
- Add appointment
- View appointments
- Update appointments
- Cancel appointments
- Store appointments in JSON
- Detect time conflicts

## Planned Future Features
- Update appointment
- Cancel appointment
- Client phone and email storage
- GUI or web version
- Database integration
- Appointment reminders
